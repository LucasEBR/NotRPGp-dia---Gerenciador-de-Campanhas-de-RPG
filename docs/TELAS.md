# Telas — NotRPGpédia (8 telas distintas)

1. **Login / Cadastro** — e-mail+senha ou login social (Google); link de "esqueci minha senha".
2. **Seleção de Perfil** — escolher entrar como Mestre ou Jogador (um usuário pode ser os dois, em campanhas diferentes).
3. **Home do Mestre** — calendário resumido + lista "Minhas Campanhas" com busca/filtro.
4. **Home do Jogador** — calendário resumido + lista "Meus Personagens".
5. **Criar / Detalhe da Campanha** — nome, sistema de RPG, descrição, geração de QR Code (com expiração), lista de jogadores/personagens participantes com filtro.
6. **Criar Ficha de Personagem** — formulário dinâmico conforme o sistema escolhido (D&D 5e / Tormenta20 / Ordem Paranormal), vinculado à campanha.
7. **Editar / Visualizar Ficha** — mesma ficha em modo edição, com upload de avatar.
8. **Calendário de Disponibilidade / Conflito de Horário** — grade semanal (jogador marca indisponibilidade) e, na visão do mestre, overlay de conflitos ao marcar uma sessão.

> Telas extras do roadmap (não contam para o mínimo de 8, mas estão no backlog): Direct Messages e Chat da Campanha — ficam para Release 4 / pós-MVP, pois não são obrigatórias e têm maior custo (tempo real).

## Fluxo (conforme rascunho em papel)

```
Login/Cadastro ──► Seleção de Perfil ──┬─► Home Mestre ──► Criar/Detalhe Campanha ──► Calendário (conflito)
                                        └─► Home Jogador ──► Criar/Editar Ficha ──► Calendário (disponibilidade)
```
