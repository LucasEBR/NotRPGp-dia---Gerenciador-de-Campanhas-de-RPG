# Backlog — NotRPGpédia

Histórias de usuário no formato: **Como** ___, **quero** ___, **para** ___.
Agrupadas por épico. Prioridade: 🔴 Alta (Release 2) · 🟡 Média (Release 3) · 🟢 Baixa (Release 4).

## Épico 1 — Contas e Autenticação

- 🔴 Como **visitante**, quero **me cadastrar com e-mail/senha ou login social (Google)**, para **acessar a plataforma**.
- 🔴 Como **usuário cadastrado**, quero **fazer login e logout**, para **acessar minhas campanhas com segurança**.
- 🟡 Como **usuário**, quero **recuperar minha senha por e-mail**, para **não perder acesso à conta**.
- 🔴 Como **usuário**, quero **escolher se estou acessando como Mestre ou Jogador**, para **ver a tela correspondente ao meu papel naquele momento**.

## Épico 2 — Campanhas

- 🔴 Como **mestre**, quero **criar uma campanha com nome, descrição e sistema de RPG**, para **organizar meu grupo de jogo**.
- 🔴 Como **mestre**, quero **gerar um QR Code de acesso à campanha com expiração**, para **convidar jogadores de forma segura e temporária**.
- 🔴 Como **jogador**, quero **entrar em uma campanha lendo o QR Code**, para **participar do grupo sem precisar de convite manual**.
- 🟡 Como **mestre**, quero **ver a lista de jogadores e personagens da campanha, com filtros**, para **gerenciar quem está participando**.
- 🟡 Como **mestre**, quero **editar ou encerrar uma campanha**, para **manter a organização do meu grupo atualizada**.

## Épico 3 — Personagens (Fichas)

- 🔴 Como **jogador**, quero **criar uma ficha de personagem vinculada a uma campanha, escolhendo o sistema (D&D 5e, Tormenta20 ou Ordem Paranormal)**, para **jogar com a ficha correta para aquele sistema**.
- 🔴 Como **jogador**, quero **editar e visualizar minha ficha de personagem**, para **manter meus dados atualizados durante a campanha**.
- 🟡 Como **jogador**, quero **excluir um personagem que não uso mais**, para **manter minha lista organizada**.
- 🟢 Como **jogador**, quero **adicionar uma imagem (avatar) ao meu personagem**, para **personalizar minha ficha**.

## Épico 4 — Agendamento e Conflito de Horário

- 🟡 Como **jogador**, quero **marcar minha grade de disponibilidade semanal (por padrão tudo disponível, eu desmarco o que não posso)**, para **que o mestre saiba quando posso jogar**.
- 🟡 Como **mestre**, quero **ver o calendário de disponibilidade de todos os jogadores da campanha**, para **escolher o melhor horário para a sessão**.
- 🟡 Como **mestre**, quero **ser avisado quando tento marcar uma sessão em um horário com conflito**, para **evitar marcar sessões que jogadores não podem comparecer**.
- 🟡 Como **mestre**, quero **confirmar a marcação mesmo com conflito, ciente do aviso**, para **ter flexibilidade quando não há horário perfeito**.
- 🔴 Como **jogador**, quero **receber um e-mail quando uma sessão é marcada**, para **ficar sabendo da data/horário sem precisar entrar no sistema**.

## Épico 5 — Comunicação

- 🟢 Como **usuário**, quero **enviar mensagens diretas para outro usuário**, para **combinar detalhes fora da campanha**.
- 🟢 Como **participante de uma campanha**, quero **conversar em um chat da campanha**, para **me comunicar com todo o grupo em um só lugar**.

## Épico 6 — Extras de Complexidade (8/8 pontos)

- 🔴 Login social (Google) — 2 pts
- 🟡 Layout responsivo (celular) — 1 pt
- 🟢 Upload de imagem (avatar do personagem) — 1 pt
- 🟡 Recuperação de senha por e-mail — 1 pt
- 🔴 Notificações por e-mail (sessão marcada) — 2 pts
- 🟢 Exportação de relatório (dados para a equipe de desenvolvimento, ex. CSV/PDF de uso da plataforma) — 1 pt
